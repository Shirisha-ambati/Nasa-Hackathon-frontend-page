# Nasa-Hackathon-frontend-page
🌦️ ClimaWatch – Weather Prediction Web App
📌 Project Overview

ClimaWatch is a responsive weather prediction web application that helps users plan activities based on weather conditions.

It provides:

🌍 Location-based forecasts
📊 Weather insights
🔐 Authentication UI (Login/Signup)
🎯 Activity-based weather suggestions
